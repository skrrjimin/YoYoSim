🔒 안전한 내 컴퓨터(브라우저) 전용 저장 방식

입력하신 GitHub 토큰 정보는 서버나 인터넷에 전송되지 않고 오직 내 컴퓨터 브라우저에만 암호화되어 안전하게 보관됩니다.
다른 방문자는 절대 이 토큰을 볼 수 없으며, 한 번만 저장해두시면 다음부터는 바로 글을 올리실 수 있습니다.

* 발급 경로: GitHub > Settings > Developer Settings > Personal Access Tokens > Tokens (classic) > [Generate new token] > repo 체크 후 생성된 토큰 붙여넣기
